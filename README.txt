AIBAZAR PWA — prototipo inicial

CONTENIDO
- Catálogo de muestra con categorías y precios ARS
- Carrito y cantidades
- Formulario de pedido
- Pedido por WhatsApp cuando se configura el número
- Manifiesto PWA, service worker y dos iconos
- Diseño adaptable a móvil y escritorio

IMPORTANTE
Este prototipo NO está publicado, NO procesa pagos y NO confirma stock real. Los productos/precios son ilustrativos. Reemplazalos antes de vender.
No recopila ni guarda pedidos en un servidor. El checkout prepara un pedido para WhatsApp.
Para activar WhatsApp, abrí app.js y reemplazá el valor vacío de window.AIBAZAR_WHATSAPP por el número comercial en formato internacional sin + ni espacios, por ejemplo 54911XXXXXXXX.
Para publicar sin pagar, podés usar GitHub Pages con un repositorio público; requiere crear una cuenta y subir estos archivos. La URL de GitHub Pages servirá por HTTPS, requisito para la instalación PWA.
Los pagos online requieren configurar una pasarela real (por ejemplo Mercado Pago) y verificar sus comisiones/condiciones vigentes. No pidas ni guardes datos de tarjetas en esta web.
